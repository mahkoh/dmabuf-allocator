# dmabuf-allocator

[![crates.io](https://img.shields.io/crates/v/dmabuf-allocator.svg)](https://crates.io/crates/dmabuf-allocator)
[![docs.rs](https://docs.rs/dmabuf-allocator/badge.svg)](https://docs.rs/dmabuf-allocator)
![MSRV](https://img.shields.io/crates/msrv/dmabuf-allocator)

dmabuf-allocator is a rust crate that can be used to allocate dma-bufs from a
number of kernel drivers and udmabuf. It is similar to GBM.

## MSRV

The MSRV is `stable - 3`.
